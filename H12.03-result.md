## What was delivered
A pure replay scrubber view model over H02.06 JSONL trajectories, built on the H05.03-04 foundation:

- `buildReplayFrames(options)` replays the recorded event stream into one immutable `ReplayFrame` per event. Each frame carries session metadata carried forward (session/task/solver/critic models), the current round/role, the event verdict plus `lastVerdict`, ascending `acceptedRounds`/`rejectedRounds`, the `pendingProposal` (latest solver proposal not yet verdicted), the workspace `files` snapshot with accepted patches applied from their accept verdict onward, and a `decisionPoint` flag (solver proposal or verdict). Solver proposals are recovered with `parseSolverPatch` from the recorded exchange responses, so file state is reconstructed purely from the recording.
- `TrajectoryScrubber` wraps the frames with seek/step controls: `seek(index)` (out-of-range/ fractional indexes return null and leave the cursor untouched), `step(delta)`/`stepBack()` clamping at both timeline ends, `reset()`, `nextDecision()`/`previousDecision()` jumping between decision points, plus `length`, `position`, `current`, `atStart`/`atEnd`, and safe degradation on an empty/blank trajectory.
- `describeFrame(frame)` renders a UI label (e.g. `round 2 · verdict accept`).

## Acceptance criteria
- **Seek/step**: covered — arbitrary seek, bidirectional stepping with end clamping, reset, decision-point jumps.
- **State matches recorded frames**: frames are precomputed deterministically from the recording order, and tests prove stepping from the start reproduces `frames` exactly, that `seek(i)` equals `frames[i]` for every position, and that seeking/stepping never leaks future state (files/acceptedRounds) backwards.

## Contract invariants satisfied
- Pure view model: no DOM, no timers, no I/O; renderer renders snapshots only.
- Immutable-from-outside state: drawer-style null-and-unchanged semantics for invalid seeks (mirrors H05.03 `selectRound`).
- Reuses H02.06 `parseTrajectory` / H02.05 `parseSolverPatch`; adds no new contracts.
