## Deliverable

A typed canonical projection of session-journal messages: stable identities
(`_message_id`, `_turn_id`, tool-call ids), origin, visibility, revision and
typed content parts, with lossless decode/encode between the plain journal

## Model

`decodeJournalMessage(row)` splits a journal row into:

- **Identity**: 32-hex `_message_id`, `turn-N` `_turn_id`, tool-call ids
  (`[A-Za-z0-9_-]{1,128}`), role ∈ {system, user, assistant, tool}; a row
  without a stable identity is rejected with `PyValueError`.
- **Origin**: `system | user | guide | assistant | tool` (guide = user row
  with `_input_kind: "guide"`).
- **Visibility**: `hidden` when `_hidden`/`_visibility: "hidden"` is set or
  the row is a compaction marker, else `visible`.
- **Revision**: `_revision` counter (0 when absent).
- **Typed parts**: `text`, `document` (structured non-string content),
  `reasoning`, `tool_call` (raw entry kept), `tool_result` (content
  presence and `is_error` preserved; absent content stays absent),
  `media_group` (the `XUENESS_MULTIMODAL_V1:` marker block; a torn block is
  refused rather than silently truncated), `media_ref` (private
  `_media_refs` entries), `hidden_reminder`, `compaction` marker.
- **Private metadata**: every key the model does not consume (e.g.
  `_revision`, `_read`, `_input_kind`, unknown fields) is preserved
  verbatim in `meta`.

## Contract invariants satisfied (C-SES-01)

- **Lossless save/restore of tool results, media, hidden reminders and
  compaction markers** — `encode(decode(row))` equals `row` (`jsonEquals`,
  key order aside); asserted for every part kind above via `roundTrips`.
- **Private metadata enters the journal but not the model-visible
  payload** — `visiblePayload` returns `[]` for hidden messages and strips
  `hidden_reminder`, `compaction`, `reasoning`, `media_ref` parts and the
  base64 media payload of `media_group`.
- **Duplicate identities explicitly rejected** — `decodeSessionMessages`
  throws on a reused `_message_id` across the session and on duplicate
  tool-call ids within one message; the same tool-call id across a call and
  its matching result remains legal.
- `canonicalSessionDigest` gives a stable, key-order-insensitive digest of
  the projection, reused by F04.02 for migration verification.
