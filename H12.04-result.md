## What was delivered
Loading/error/empty visual states for the critic review drawer, on top of the H05.03-04 view model:

- `CriticDrawerVisualState`: `"idle" | "loading" | "ready" | "empty" | "error"`.
- `CriticDrawerStatus`: `{ state, message, retryable }` — a paint-ready snapshot per state with human-readable messages ("Loading critic review…", "Critic finished without review rounds.", the captured failure message, …); `retryable` is true for `empty` and `error`.
- `CriticDrawerController`: pure async orchestration around a caller-supplied `load()` fetch. `refresh()` drives idle → loading → ready/empty/error; concurrent `refresh()` calls share one in-flight load (single `load()` invocation, one attempt counted); a failed reload never blanks an already-open review (last successful drawer retained through reloads and failures); non-Error rejections and blank messages degrade to a generic error message; empty results (zero rounds) surface the `empty` state with the underlying drawer still queryable (`activeRound` null, workspace snapshot unchanged, accept is a no-op decision). Requires a non-empty task like the drawer it wraps.

## Acceptance criteria
- **Loading state covered**: state is `loading` while the fetch is in flight, drawer not yet painted, stale review retained during a reload.
- **Error state covered**: rejection captures the failure message into `status`/`error`, marks `retryable`, keeps the prior drawer, and recovers to `ready` on a successful retry; non-Error rejections degrade safely.
- **Empty state covered**: zero-round result → `empty` state, retryable, `activeRound` null, `appliedFiles()` unchanged, no-op accept decision.

## Contract invariants satisfied
- Pure view model: no DOM, no timers; async load is caller-driven and awaited externally.
- Immutability preserved: the controller forwards a copied `files` baseline into the rebuilt drawer; existing H05.03/H05.04 exports and semantics untouched (all 13 pre-existing tests still pass unmodified).
- Reuses H02.05 `CriticSolverResult`; adds no new cross-module contracts.
