## Contract invariants satisfied

- **Manual-only entry**: no scheduler, hook, or background worker starts a dream; the only `setInterval` is a 50 ms abort watchdog inside an already-started dream, so nothing runs without an explicit `start` call.
- **Explicit approvals**: start needs `confirmed` + matching `startDigest` + `allowReal` + host switch; apply/revert need `confirmed` + matching digest; nothing applies or reverts project memory implicitly.
- **Safety**: one dream per workspace root (lease); base KEY and every captured source are re-digested before start and reject on drift; apply is CAS-guarded and revert refuses when project memory drifted or the owner session is read-only; candidate content is treated as untrusted data (redaction + strict JSON + no tool execution beyond read-only tools).
- **Boundaries**: collection reads (`list`, `get`, `diff`) are GET/read-only; only `start`, `cancel`, `apply`, `revert` are mutating POSTs; the remote protocol allowlist mirrors exactly this set.
