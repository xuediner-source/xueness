## Contract Invariants Satisfied
- **Multiple calls share defined state**: one vm context per owner session; top-level bindings (`const`, `let`, implicit globals) and imported modules survive across calls (`total + 1` after `const total = 21`, `path.join(...)` after a previous `await import('node:path')`).
- **Reset truly isolates**: `reset` swaps in a fresh context under a new epoch; pre-reset bindings are gone (`typeof gone === "undefined"`) while the session identity continues, and results carry the epoch so stale responses are visible.
- **Long calls are cancellable**: every run is bounded (default 10 s, cap 60 s). Synchronous infinite loops are cut by the vm script timeout and never-settling `await`s by a promise race — both settle as `tool_timeout` and the session stays usable; state written before the timeout survives; a pre-aborted `ToolEnv` signal settles as `cancelled`.
- **Instances are reclaimed with the session**: `dispose()` closes the manager (further runs reject with `sessions_closed`), drops every context, and runs registered host-cleanup hooks; per-session reclamation also exists (`disposeSession`) and the session cap (16) bounds footprint.
- **Host capability ports**: captured `console` (output), `nodeImport(name)` shim + dynamic `import()` with a resolver (modules), `nodeReset()` (reset from inside the sandbox), abort-signal port, and dispose hooks — the tool declares `requires: { exec: ["*"], fs: { write: ["state"] } }` because sandboxed code runs with host privileges.
