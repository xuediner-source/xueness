# 可靠性、搜索模型与客户端更新

## 功能归属

所有本轮功能继续使用可信插件目录。在「设置 → 插件 → 已安装功能插件」中可查看完整目录、子功能和有效状态。

| 插件 | 本轮能力 |
| --- | --- |
| desktop | Windows/macOS 集成标题栏、原生窗口控件、按平台显示快捷键 |
| network | 搜索服务和独立搜索模型 API、连接诊断、Fake-IP 环境的显式真实 DNS 路径、结构化失败原因 |
| providers | 对话、真实工具调用、工具往返、流式输出兼容诊断；采用已通过验证的兼容配置；实际用量和步骤计时 |
| planning | 持久交付清单，文件、必需人物或内容、来源链接数量检查；用户可编辑，模型不能削弱已有要求 |
| updates | 稳定版检查和下载、取消、安装前检查任务状态、Windows 重启安装、Mac 下载并打开 DMG |

启用插件不会授予模型工具权限。关闭插件后相关按钮、HTTP、模型工具和后台 effect 不再发起工作。桌面端通过私有父进程管道同步插件有效状态，渲染器不能提供安装路径或更新源地址。

## 本地模型接入

在「设置 → 模型设置」保存连接后，分别运行对话、工具、工具往返和流式诊断。工具诊断使用固定算术工具，必须返回正确名称和参数；它不会执行文件操作或系统命令。流式诊断需要完整的终止标记，不能把收到一段文字当成完整成功。

通过必要检查后，可明确采用已验证的兼容参数。修改地址、密钥、模型或连接配置后，旧检查失效，需要重新验证。测试会发真实 API 请求；本轮开发回归使用隔离的 HTTP wire fixture，没有代替用户在 Windows NInfer 上的验收。服务只在用户 Windows 电脑上运行，本开发环境未直接访问它。

「步骤耗时与实际用量」分别显示模型请求、等待、思考流、生成流和工具执行耗时，以及服务实际报告的输入、缓存、输出 Token 与失败重试次数。流数据时段包含传输等待，不等于服务器 GPU 计算耗时。非流式请求不能拆出思考和生成；缺失指标显示 `—`，字符估算不能替代 Token 统计。

## 搜索模型 API

「设置 → 网络搜索」可选择搜索服务或独立的 OpenAI-compatible 搜索模型，并填写 API 地址、模型 ID 和密钥。配置与主对话模型分开，密码输入框不会回显已保存密钥。空输入保留密钥，删除使用明确的清除操作。公网地址检查继续生效；不能利用代理或 DNS 配置读取本机或内网地址。

搜索模型必须返回来源链接，结果标明模型来源及验证范围。模型生成的来源并不自动证明网页可达或事实正确，应继续使用网页读取核对。搜索密钥缺失、受阻 DNS、权限拒绝和等待用户批准是不同状态；不可重试错误暂停运行并显示可操作原因。

## 证据与交付检查

宿主给成功调用分配 `E1`、`E2` 等短编号，持久映射到真实调用 ID。模型最终报告优先引用 `evidence_id`，旧的真实 `tool_call_id` 仍兼容；伪造编号不能通过。引用有误时在剩余步骤预算内最多定向修复一次，修复不能重做工具操作。

报告和文件任务应先用 `delivery_plan` 登记所有要求；原任务中的明确文本输出文件名也会进入初始清单。用户可以在会话中编辑人物或必需文本、目标路径和最少来源链接。完成时宿主读取工作区内的实际文件核对，不能把模型自行标记完成当成证据。报告类交付的目标文件必须包含文本；普通文件任务仍可要求零字节文件。

界面分别显示「工具执行成功」与「交付检查通过」。未登记清单显示「交付内容尚未检查」；清单缺少的人物、文件或链接逐项列出。检查通过仅指声明的文件和文本要求，不保证事实真实性、链接可达或清单之外的要求已经完成。旧会话的工具验证不会自动升级成内容验证。

## 桌面更新

更新源固定为本仓库的 GitHub 稳定 Release。启动时检查，此后定期检查；可以关闭自动下载、手动检查、下载和取消。不会自动中断任务安装。选择「重启并更新」时检查会话、工作流、子任务、终端及进行中的操作，关闭新任务入口，停止宿主拥有的进程，再调用 Windows NSIS 安装器。检查、下载完成和安装完成是不同状态。

v0.1.0 没有更新器，需要先升级到带更新器的版本一次，后续安装版可在客户端接收更新。Windows 便携 ZIP 不支持原地 NSIS 更新，应改用安装版。当前 Mac 包尚无签名或公证：客户端能下载经过大小、SHA-256 和固定来源校验的对应架构 DMG，并打开安装器，仍需在 Finder 中替换应用；不会声称它已自动安装。源码和开发模式不自动检查网络更新。

发布时必须同时上传 Windows `latest.yml`、安装包和 blockmap，保留其版本、文件名、大小及 SHA-512 的对应关系。Mac 不同架构的元数据不能互相覆盖；当前 unsigned 路径按同一 Release 的对应架构 DMG 和 SHA-256 选择。

参考的是 [ZCode 更新源代码](https://github.com/zai-org/ZCode/blob/main/packages/desktop/src/main/autoUpdater.ts)、[DeepSeek Harness 更新协调器](https://github.com/deepseek-ai/deepseek-harness/blob/main/apps/desktop/src/update-coordinator.ts)、[Codex 应用内更新配置](https://learn.chatgpt.com/docs/config-file/config-reference) 和 [Electron 更新平台约束](https://www.electronjs.org/docs/latest/api/auto-updater/)。Codex 公开文档确认应用内更新默认启用；Xueness 的具体实现由自身的 Electron 宿主和插件提供。

## 共享基础设施审查

本轮新增的宿主证据别名、一轮引用修复、插件完成检查回调属于 AGENTS.md 已列出的通用完成验证与 journal 协议；具体交付业务位于 planning 插件。HTTP 的请求登记与关闭接入属于通用安全和生命周期边界，供安装前保证正在进行的写操作不会被中断；安装决策、版本、下载来源和用户控制属于 updates 插件。结构检查脚本的共享白名单没有因此扩大。
