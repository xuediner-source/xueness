# Windows 会话体验 0.1.7

本次改进参考本地 Codex、Claude 的桌面实测材料，由 Xueness 自身组件实现，没有复制它们的商业前端 bundle、图标或商标。已有第三方代码的许可证和 NOTICE 保留。

## 使用变化

- 新会话下方提供「看懂一份资料」「整理一张表格」「做出一个小工具」。点选会把任务说明追加到输入框，保留已有文字和附件；可修改后发送。
- 附件与上下文下方可展开「本条消息材料」，核对这次实际提交的引用，以及尚未就绪的附件。
- 中断回答下方提供「接着做」，将继续任务的说明放入草稿。模型连接失败则使用原有重试运行操作；不会同时显示相互矛盾的停止和失败提示。
- 需要复核与运行失败使用不同状态，队列、搜索与轻量栏保持一致；没有把模型自述当成验证证据。
- 交付清单中的文件显示独立卡片、检查状态和打开入口。文件插件关闭时保留清单，但不显示打开按钮；规划插件关闭时不挂载交付卡片。
- 模型监测保持紧凑，具体型号与异常仍可查看。扩展市场不再为订阅中心、模型监测单列推广按钮，统一使用「管理已安装插件」；聊天页不推广停用插件。
- 第二套外观显示为「纸感」。旧的外观配置标识保留兼容，用户无需重新设置。
- 修正侧栏排序菜单的定位，菜单文字不会再弹出窗口左边界而留下白色空面板。
- 项目行支持右键菜单，也支持键盘菜单键及 Shift+F10。「从项目列表移除」只移除该列表入口，文件和会话保留，时间线仍能找到会话。再次添加该文件夹即可恢复项目入口；移除状态保存在侧栏偏好中。

## 完整退出后的恢复

桌面版草稿、提示历史、分屏布局与侧栏偏好现在保存在当前应用数据目录的 `desktop-state-v1.json`，不再依赖每次启动都会变化的本地 HTTP 端口。标准和轻量布局分别记住侧栏的收起状态。Web 版仍使用站点自身的浏览器存储。

附件在该文件中只保存既有持久引用，附件内容仍由会话插件的存储管理。原来的工作区、会话、模型配置和插件开关位置保持不变。升级前随机端口下的旧浏览器记录没有被删除，也不自动扫描或合并归属不明的记录；本修复保护升级后保存的草稿与布局。

## 开发与验收

桌面存储属于 `desktop.lifecycle` 已有宿主恢复基础设施，前端消费者仍由 sessions 功能开关控制。桥只提供固定键的 get/set/remove，不暴露文件路径或通用 IPC。权限、模型请求与工具审批继续由现有运行链路决定。

新增功能归属：`sessions.starter_ideas`、`sessions.material_manifest`、`sessions.approval_impact`、`planning.deliverable_files`。监测收拢扩展 `model_monitor.home`；会话、侧栏与恢复扩展原有 sessions 功能。

验收区分三种证据：组件 fixture 验证交互与状态；真实 Electron 进程退出再启动验证持久化；真实模型样本验证会话链路。fixture 不作为模型性能或成功率。完整重启要核对新 PID、后端新端口、两个分屏草稿、同一上传附件引用和侧栏宽度，不能用 `page.reload()` 代替。
