# Windows 0.1.8：输入与项目菜单

本次更新归属于现有 sessions、model_monitor 与 desktop 功能插件。

- 输入区用“引导 / 排队”轻量按钮选择后续消息的处理方式。菜单解释两者区别；待处理消息显示为输入区上方的单行横条，右侧保留取消和更多操作。更多菜单使用原有编辑、撤回、调整顺序与立即发送行为。
- 项目右键菜单提供置顶、编辑显示名称、分区、在资源管理器中打开、归档聊天和移除项目。编辑名称不改磁盘目录；项目偏好随重启保留。归档保留会话记录并跳过运行中的会话；移除项目不删除目录或会话。
- 原生资源管理器操作属于 desktop 插件，使用已有工作区边界确认目录，通过系统 shell 打开。关闭其相关插件后不执行原生打开动作。
- 模型监测记录页增加外边距和记录间距，桌面宽度并排展示请求与返回型号，窄屏改为纵向布局。记录仍来自会话响应，不额外请求模型。
- 新会话不再显示自动声明的 image、pdf、video 能力标签。实际附件和主动选择的技能等上下文仍正常显示，模型能力配置保留。

验收使用独立临时状态。截图里的项目、队列及模型监测示例为合成数据；本轮界面验收不发起模型请求。
