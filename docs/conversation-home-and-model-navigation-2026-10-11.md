# 会话主页监测、模型分类与用量布局

本轮目录为 **30 个可信插件、192 项登记功能**。新增功能仍由插件实现，保留已有模型配置、会话与开关；订阅中心和返回模型监测仍由用户选择安装。

## 会话里的返回模型监测

归属 `model_monitor.home`：新会话页与当前会话页直接显示监测卡，包含请求型号、接口返回型号、匹配状态和记录入口。详情可展开；记录入口直接打开监测面板。未安装或停用时只显示共享插件管理入口，业务组件、读取和轮询均不挂载。

响应记录新增可选的本机会话 ID。主页只读取当前会话的记录，切换会话会中止旧请求。旧记录没有会话 ID，仍保留在全局历史中，不猜测其归属；新会话页不会拿其它会话的响应充当本次证据。模型选择改变时，上次响应与下次请求分别说明。型号来自响应字段，不代表对底层模型或灰度版本的认证。

`PluginHomeEntry` 属于既有共享插件安装／恢复基础设施，只展示目录名称、安装状态和导航，不运行停用插件的业务 effect；未扩大架构白名单。容器仅挂载组件、传递会话标识、选择状态与已有导航动作。

## 模型供应商子菜单

归属既有 `sessions.model_picker`，供应商元数据由 providers 插件提供。菜单先列供应商与数量，再进入该供应商的型号列表；搜索可以跨供应商查找。保留原始 profile ID、未配置状态、运行档位、设为默认、推理和详情／编辑功能。

订阅型号按目录中的账户接入项分组；手动配置按接口主机与端口分组。分组只影响导航，不改变路由、账号或默认选择。公开元数据不包含 URL 用户信息、路径、查询参数或密钥。支持方向键进入／返回、上下键移动、Escape 清除搜索／返回／关闭，以及焦点恢复；列表不产生横向滚动。

## 用量布局与颜色

归属既有 `usage.tokens`／`usage.costs`：统计卡增加留白并按实际内容宽度换列；图表增加间距与高度。每日 Token 图按照已有每日型号明细堆叠，图例、型号列表圆点和用量条使用相同的稳定颜色。颜色由模型与协议决定，不受排名、统计周期或刷新影响。

缺失型号归属保留为灰色，不把未归属总量分配给某个模型。没有实际报告的 Token 和价格仍不估算。热力图使用独立的活跃度色阶，月份标签不裁切。

## 订阅运行失败的修正

用户报告的 `ee318b9f36dc4891` 在原日志中仅记录 `core.run` 的 `ValueError`；附近失败属于 Antigravity 请求，但没有上游状态码，不能据此断言具体上游原因。已修正订阅桥接将所有上游错误误报为 `local run failed` 的问题：传递脱敏的错误类别和 HTTP 状态，接入既有 `ProviderRequestError` 契约，区分认证、限流、额度、上下文、区域、连接和响应错误。回调异常保留为本地错误，合作取消仍正确停止。

原生订阅适配器接收本机会话标识，让 Antigravity 思考签名缓存与续轮工具调用绑定同一会话。验证使用隔离账号和本机／内存协议 fixture，没有调用真实订阅账户或收费模型。

## 验证

按用户要求仅运行相关检查，不运行全量测试：插件架构门禁、相关 Python 回归、前端定向回归、订阅协议 fixture、类型检查与生产构建。真实构建验证覆盖两种外观的深浅色、窄窗口、供应商导航／搜索／键盘、三个型号的彩色堆叠、跨会话隔离和监测停用后的无轮询。桌面更新仅替换程序目录，原数据与插件状态保留。
