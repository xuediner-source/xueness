# 项目选择与会话历史导航

2026-10-01。按用户要求，本轮项目选择采用简洁的本机文件夹流程，会话左侧增加历史导航条。

## 添加项目

侧栏项目工具栏的加号打开“添加项目”。窗口提供“在此电脑添加文件夹”和最近目录，目录浏览与新建文件夹放在次级入口。开始界面的“打开文件夹…”使用同一流程。

在 macOS 本机连接中，主机调用系统文件夹选择框。取消不修改项目列表；成功选择后，具体目录登记到工作区设置，立即用于会话、文件浏览、记忆和终端，无需重启。登记值保存在本地，服务重启后仍可读取。界面不会初始化 Git 或移动已有文件。

项目列表也显示尚无会话的已登记目录，每个项目可以直接新建任务。切换到另一目录会开启新任务，已有会话的目录保持不变。新建子文件夹后自动进入新目录，减少再次查找和选择的步骤。

系统选择框目前支持 macOS 的本机连接；不支持的平台与远程连接保留受主机范围约束的目录浏览。手工提交路径、保存默认目录不会扩大目录范围；原生选择结果才可登记新根。POST 使用现有同源、Host、CSRF 防护，并校验实际连接来自 loopback。脚本参数通过 argv 传入，不拼接路径为代码。

## 会话历史条

会话左侧短横线对应消息流中的真实用户提问。当前阅读轮次显示较长的高亮横线；悬停或键盘聚焦预览提问和公开回复，点击定位到对应消息。方向键、Home、End 移动焦点，Enter 确认跳转；导航条自身滚动会保持当前点可见。

阅读历史时，新消息不会强制拉回底部；滚到末尾后恢复自动跟随。首条用户消息从保存的 journal 补入显示层，events v1 协议保持不变。事件列表按首请求的 head 快照继续读取后续分页，避免前 200 个事件之后的内容丢失。

导航范围是当前保存消息流；本轮没有为上下文压缩后移入 archived_messages 的记录另建完整历史阅读器。
