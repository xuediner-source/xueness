## 已确认问题与修正

| 问题 | 影响与处理 |
| --- | --- |
| Mac 启动验收引用失效的 `session` 变量 | 窗口安全初始化提取后，打包启动验收会抛出 ReferenceError。改为使用当前窗口的真实 session，补生命周期回归。 |
| 启动过程中关闭 Mac 窗口 | 后端就绪后可能继续使用已销毁窗口。恢复有效窗口后再绑定安全策略并加载工作台。 |
| Mac 关闭窗口后二次启动 | 原操作继续访问已销毁窗口。二次启动与 Dock 激活共用窗口恢复入口，退出期间不重建，加载失败明确退出。 |
| POSIX 父进程检测直接 `os._exit` | 隔离进程复现显示：脱离启动器的工作流被杀死，命令子进程继续运行，状态停在 running。撤回该新增硬退出，保留已有桌面 owner 检测、协作取消和进程回收；增加两类生命周期回归。 |
| Windows broad-root 检查错误涵盖 UNC 目录名 | `Users`/`ProgramData` 可以是网络共享中的普通项目目录。限制新增系统目录规则为盘符根目录，并测试大小写与 UNC。 |
| Windows 便携包资产名改变 | 已有文档和 Release 链接使用 `-portable` 后缀；保留原名并增加回归，避免链接失效。 |
| 程序化滚动被误判为用户上滚 | 修正跟随状态和滚动来源判定，并检查真实浏览器中的历史跳转、贴尾与恢复。 |
| 页面渲染计时被当成总工作时间 | 从首次看到流式行开始的 performance 计时不能证明任务总耗时。移除该数字回退；缺少真实时间戳时显示工作状态，不编造时长。 |
| 会话基础布局依赖懒加载的子代理样式 | 未打开子代理侧栏时，长会话能把消息区撑到数万像素，输入框落到窗口外。把基础会话容器布局迁回始终加载的 sessions 样式。 |
| 恢复阅读位置时虚拟列表重新贴尾 | 虚拟列表首次定位与尺寸观察覆盖了已保存的位置。会话视口传递初始跟随状态，恢复、缩放和新增消息后保留阅读位置。 |
| 恢复输出仍显示“已中断” | 相同文本恢复流式输出时，旧 interrupted 标志未清除。显式更新当前状态，并保持未变化行的引用稳定性。 |
| 推理滑块延迟写入旧模型 | 在延迟保存前切换模型，旧档位可能写入新模型。按模型和档位范围约束待提交操作，切换或卸载时取消。 |
| 失败信息复制误报成功 | 剪贴板写入未完成即显示成功。仅在写入成功后提示，拒绝和不可用时保留正确反馈。 |
| 减少动态效果模式仍有滑块动画 | 针对该系统偏好直接关闭星点和能量动画，保留可操作状态和文本提示。 |
| 窄窗口模型详情遮挡标签和选择项 | 在 420px 生产构建复现详情卡“编辑”按钮拦截点击。统一按 border-box 计算宽度，详情卡放在菜单外侧，空间不足时置于整个菜单上方或下方，保留鼠标和键盘操作。 |
| 非 Mac 平台初始显示 Mac 权限步骤 | 初始平台不再一律猜测为 darwin，避免异步读取前出现不适用的授权说明。 |
| Windows 麦克风动作名称不准确 | 原生操作只打开 Windows 设置；按钮和说明明确表达这个行为，不宣称已弹出授权。 |

## 功能归属与数据真实性

推理档位滑块、历史预览、阅读位置记忆、工具执行状态、失败信息复制及中断提示都由 sessions 插件提供，复用已有功能 ID；全部新增实现模块登记在 manifest。desktop、onboarding、providers、settings 和 updates 的扩展沿用各自插件边界。目录仍为 28 个插件、147 项功能，关闭插件不授予额外权限。

`xuenessShortcutDisplay.ts` 仅格式化平台快捷键标签，属于共享基础 UI；共享理由已补入 CONTRIBUTING。它不监听键盘、读写配置或执行动作。

交接中的 `messageTimeLabel.ts` 是尚未接入生产时间线的格式化辅助函数，不能据此声称已经显示真实消息时间。事件协议没有提供每条回复的开始/结束时间时，不显示虚构的总耗时。工具调用成功和交付检查通过继续分别展示。
