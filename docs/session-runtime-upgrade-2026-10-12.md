# 会话执行与恢复升级

实施顺序：当前轮引导 → 稳定历史与增量推送 → 语义压缩 → 目标驱动 → 子会话恢复。

功能分别归属 sessions、providers、planning 和 subagents 插件。共享 Store 增加稳定身份与有序历史基础设施；执行循环仅增加受插件有效状态控制的生命周期接口。已有 JSON 会话、权限、审批和文件恢复仍使用既有入口。

验收使用隔离状态、离线 provider 和真实构建的桌面/窄屏界面，不访问实际模型服务。重点覆盖：轮次结束竞态、消息重试、历史编辑/压缩后的重连、日志截断、摘要失败/取消、目标预算/暂停/无进展、子执行中断与恢复不重复工具副作用。

原始工作区改动及将修改文件的备份：`E:/models/apps/xueness-optimization-20261012`。

参考实现固定到本地官方 ZCode `aac4755666d09fdcd70272fcf063c077a639015f`（v3.15.1）。用户界面使用 Xueness 名称；复用源码的必要许可证和版权声明保留。界面行为、运行机制和恢复行为分别验收，单元测试通过不能代替视觉一致性或真实模型表现。

## 稳定历史和实时更新

每条消息保存私有 `_message_id` 和 `_turn_id`，提供商请求剔除私有字段。当前轮引导属于原有人类轮次，事件协议与完成证据仍按原轮次归并。消息编辑或压缩后，界面使用稳定消息身份维持展开状态。

`<session>.history.jsonl` 保存带链式校验的有序修订，以 set/delete/append 操作记录变化；现有 JSON 继续作为兼容检查点。只有未换行的最后一条记录允许作为中断写入恢复，完整损坏记录拒绝继续写入。JSON 发布成功但修订发布失败时，下次读历史写入明确 reset 修订并要求旧游标重新同步。

`GET /api/sessions/:id/history` 返回有界修订页。`GET /api/sessions/:id/updates` 对 SSE 客户端先发送完整 conversation.snapshot，再发送带 baseRevision 的 conversation.patch；每次重连都从权威快照开始。客户端拒绝失配补丁、关闭无效流并回退轮询；切换会话或关闭 sessions 插件释放连接。冻结的 events.v1 仍是兼容显示协议，并非新增修订日志。

## 当前轮输入和目标执行

运行中默认引导当前轮，可切换到后续队列；快捷键的反向发送遵循参考实现的 guide → queue、queue → startNow 行为。引导使用持久收件箱及请求 ID，只有模型请求边界才能消费；原始工具批次不中断。过晚到达的输入暂停保留，可撤回到输入框重新选择。排队消息立即发送先取得预留回执，等待旧执行器退出，再建立新的明确用户轮次；重复回执不会再次追加或恢复旧工具批次。

providers 插件使用当前绑定模型的独立纯文本请求生成结构化摘要，验证原始用户要求覆盖、保留当前轮及闭合工具结果，保存成功后替换上下文。失败或无效摘要回到原始历史，用户停止与外层截止时间仍沿既有取消路径结算。

planning 插件目标具有独立生命周期和累计轮次、时间、可选已报告 Token 预算。最终回答在安全边界由独立核验判定；措辞“目标完成”不构成完成证据。待回答、待批准、停止、禁用、无进展和预算到达都会停止自动继续；手动恢复才重建明确的预算分配。主执行器负责正常消息持久化和循环，不授予额外工具权限。

## 子会话及分享

subagents 插件保留独立子会话、父/根身份、消息和工具记录；恢复使用当前父执行器，保持只读能力边界。未闭合的执行不能自动重放，已取消子任务不能恢复，已完成子任务需要明确补充消息。消息收件箱在安全边界接收内容，侧栏可查看独立子会话正文。

分享记录仅保存用户选定轮次的文本、标题和时间，使用当前配置的 Xueness Web 主机提供只读链接。`POST /api/sessions/:id/share` 绑定当前消息修订；`GET/DELETE /api/conversation_shares/:id` 查看或撤销，`POST /api/conversation_shares/:id/import` 创建暂停的新会话。模型凭据、执行授权、工作区路径、工具结果对象和目标运行状态不随分享导入。该本地主机分享不使用 ZCode 官方云分享服务。

只读分享的 `/share/:id` 页面由 sessions 插件提供。共享 HTTP 层只分发有效插件的页面回调，不加入会话业务路由；插件关闭后页面入口停止工作。隔离生产界面检查确认真实链接返回 200，查找和窄屏分享可用，没有外部请求或模型调用。
