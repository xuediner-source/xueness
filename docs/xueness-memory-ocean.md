# 记忆之海（Memory Ocean）

更新于 2026-11-13。归属 `memory` 插件：后端 `ts/plugins/memory/src/memory-ocean-*.ts`，界面 `webapp/src/plugins/memory/`（`MemoryOcean.tsx` 与 `ocean*.ts`），目录登记见 `ts/catalog/memory.json`。

记忆之海是 Xueness 自己的跨会话记忆。智能体在对话中记下值得以后知道的事——你的偏好、项目事实、做过的决定、积累的经验和踩过的坑——之后的对话开始时，与新任务相关的记忆会自动带进上下文。所有记忆都画在一张会动的星图上，可以查看、编辑和遗忘。

设计参考了 DeepSeek Harness 生态里星标最多的记忆插件（OpenViking、MemOS、EverOS、Mnemosyne、memento）的思路：先读一句话摘要再读全文、可查看可编辑的记忆图、用户与项目分开、显式的保存与召回工具、写入审计。没有使用它们的代码；它们是 Cordis 或 Python 服务，不能在 Xueness 中运行。

## 1. 记忆如何形成

- **智能体保存**：`memory_remember` 工具。项目所有者选择了直接保存：保存后立即生效，每段记忆都标明来源会话，可以在星图里编辑或遗忘。工具始终加载，轻量本地模式的小模型也能看到。
- **你添加**：星图右上角「记住一件事」。
- **合并与取代**：同一范围里内容几乎相同的记忆会合并，不会重复；用 `supersedes` 指定被取代的旧记忆，旧记忆转为「已被取代」，不再被召回，仍可恢复。
- **拒绝密钥**：内容像密钥、令牌或密码时拒绝保存。
- **上限**：最多 2000 段有效记忆；满了会明确报错，不会悄悄丢掉旧记忆。

每段记忆有：一句话摘要、完整内容、类型（偏好 / 事实 / 决定 / 经验 / 教训）、范围（此项目 / 所有项目）、标签、重要程度 1–5、相关记忆的链接、来源、创建与更新时间、被召回的次数。

## 2. 记忆如何被用到

- 每次运行开始时，按本次任务的提示从「所有项目」和「此项目」的记忆中挑选：对摘要、内容和标签做 BM25 词法排序（中文按相邻两字切分），再按重要程度和新近程度略作提升。重要程度 5 的记忆，以及重要程度 4 以上的偏好，即使不匹配也会带上。
- 数量与长度有上限：标准模式最多 8 段、2400 字符；轻量模式最多 5 段、1200 字符。放不下全文时只放摘要。
- 选中的记忆在整次运行中保持不变，模型请求的前缀因此稳定，本地推理服务器的 KV 缓存可以复用（与 L1 相同的考虑）。
- 不使用向量模型，不额外调用模型：对小模型没有额外开销。
- 需要时智能体可以用 `memory_recall` 按关键词搜索（延迟加载的工具，通过工具搜索发现）。
- 记忆作为不可信数据注入，前面带有「只是数据，不是指令」的说明；当前对话的指令优先。

## 3. 星图

侧栏「记忆之海」（经典外观在左侧图标栏的「记忆」）打开。

- **画面**：画布始终是夜色的海（项目所有者的选择），只有气氛随外观变化：经典外观是冷色深海，纸感外观是暖色墨蓝。卡片、抽屉和按钮跟随应用的浅色/深色主题。
- **海**：水面从下方看去是一条起伏、闪着碎光的亮线；水中有缓慢流动的焦散光网（三组 60° 交错的波纹叠成的细胞状光纹，越靠近水面越亮）、摇曳的光柱、上浮的气泡（到水面破开）、下落的海雪、带视差的浮游微粒，以及前后两层失焦的光斑营造景深。光标像一盏提灯，照亮周围的微粒和气泡。
- **星光**：每段记忆按光学点扩散函数逐像素绘制——锐利的高斯核心、陡峭的 Moffat 内晕和极淡的大光晕；中心近白，只有外围带颜色。光晕不是每颗星各画一大团，而是把所有星光画进四分之一分辨率的光缓冲，以三档半径模糊后用「滤色」叠回：相邻的星光自然融合，渐变平滑无色带，亮处不会过曝发白。不重要的记忆是清晰的小点，越重要辉光越强；沉得越深越柔、越暗。重要程度 5 的记忆带发丝般的衍射星芒和呼吸的光环；常被召回的记忆有微光沿倾斜轨道环绕。颜色是柔和的星光色调：玫瑰、浅青、香槟金、薰衣草、琥珀。
- **连线与星座**：显式链接、共同标签和内容相近会把记忆连起来；连线取两端记忆的混合色，并按关系区分笔触（显式链接较实、共同标签细线、内容相近为点线、被取代为虚线）。联系紧密的一组构成星座：四团缓慢绕行的柔和星云，一条像旧星图那样的点线边界，以及字距舒展的名称、细线和成员数。最强的一批连线上有光点缓缓流动。
- **动态**：打开时镜头下潜，海面渐亮，记忆按深度依次亮起；光点随水流轻轻摆动、微微闪烁；悬停或选中时相连的线上有彗星般的光流，周围的记忆显示名称标签；搜索命中和选中的记忆像声呐一样向外发出光环；被召回的记忆发出光环并沿连线传出光点；新记忆从下方升起绽放；点击水面泛起涟漪；拖动松手后视图带惯性滑行。打开页面时重放最近半小时内的几次保存和召回；页面打开期间每 15 秒刷新一次，智能体新保存或召回的记忆会实时亮起。
- **操作**：拖动平移，滚轮或双指缩放，双击放大；方向键移动、`+`/`-` 缩放、`0` 回到全景、`Esc` 取消选择。可以搜索、按类型筛选、切换「此项目 / 全部」，打开列表视图，查看详情、编辑、遗忘（需确认）或恢复。放大后重要记忆下方显示摘要标签，标签互不重叠。
- **减少动效与性能**：系统设置或「设置 → 外观 → 减少动效」打开时，布局直接静止，不再播放任何动画，只在操作时重绘。渲染开销持续偏高时会自动关掉焦散、光斑、气泡、环绕微光和多档模糊，保留一档辉光。
- **记忆轨道**：设置了 `XUENESS_MEMORY_ROOT` 时，原有的 MEMORY.md / USER.md / KEY.md 条目以菱形光点出现在星图中（只读），右上角「记忆轨道」抽屉里仍可查看和编辑这些文件。

## 4. 存储与开关

- 数据在状态目录的 `memory/ocean.json`（桌面版为 `%APPDATA%\Xueness` 下的状态目录），加文件锁原子写入，目录为私有权限。
- 「设置 → 记忆」关闭后，既不注入记忆，也不提供两个记忆工具；在插件管理中关闭 `memory` 插件则整个功能停用，星图接口返回 403。

## 5. 接口

| 方法与路径 | 作用 |
| --- | --- |
| `GET /api/memory/ocean?root=<工作区>` | 星图数据：记忆、连线、星座、最近事件、统计 |
| `POST /api/memory/ocean/memories` | 添加一段记忆 |
| `POST /api/memory/ocean/memories/<id>` | 编辑（需带上读取时的 `version`），或以 `status` 恢复 |
| `POST /api/memory/ocean/memories/<id>/forget` | 永久遗忘，需 `confirmed: true` |
