# 会话与 Windows 适配同步说明

本次同步完善连续会话、后台会话切换和消息队列，减少内部 JSON 协议及重复总结展示，保留真实错误、待批准操作和用户问题。浏览器设置集中在设置中心，桌面 Chrome 资料导入沿用任务、进程占用和工作区边界检查；托盘菜单、标题栏及资源监测展示保持紧凑。

后端修复包括 Windows MCP 启动器及后代进程回收、清理失败后禁止重启与版本重试、文件私有 ACL、junction/reparse point 存储边界、归档身份检查、越界 glob 和无效用量时间戳处理。消息队列在写入提示词前保护文件权限；归档在会话租约和队列锁内删除队列，恢复后不重放旧输入。Chrome 导入目录及 worker 使用的资料目录在复制或启动前设置可继承的私有权限，失败时停止写入或启动。修复与功能仍归属原有插件和共享基础设施，不扩大用户授权。

Composer 草稿按会话保存，在临时卸载后保留。异步发送仅在对应草稿的版本未变化时清空，避免旧请求返回后丢失其他会话或本会话的新输入。源代码同步包含相应测试、插件 manifest、使用文档和预构建 Web 资源，不包含个人状态、模型文件、凭据或本机安装包。
