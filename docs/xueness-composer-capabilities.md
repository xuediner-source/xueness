# 添加能力、上下文与完全访问

发送和会话过程：提交后输入框立即清空，创建、入队或追加消息被宿主接受后即可编写下一条，不必等模型结束。提交被拒绝时恢复原草稿；期间输入的新内容不会被旧请求覆盖。工作过程与最终回答分开，正常完成默认收起，异常或未完成默认展开。点击过程标题查看思考、说明和工具；工具详情独立展开。终端详情优先显示命令与实际输出，点击「原始工具数据」可查看完整参数和结果。顶部请求状态是紧凑入口，可打开查看实际 Token 和步骤耗时。详细依据与验证见[会话实机对照记录](conversation-zcode-review-2026-10-07.md)。

在输入框的「+」中选择附件、会话目标、工作流，以及插件/技能创建器、Xueness 指南、PDF、演示文档、电子表格、Word、浏览器和搜图。选择能力会在草稿中留下可移除的标签，并由后端插入对应的可信工作流说明；它不会自动安装插件或授予权限。灰色项目表示所属插件或依赖未启用，可从「管理插件」恢复。轻量档也保留这个入口。

菜单使用紧凑列表，支持搜索能力、文件、会话与技能；选择后立即在输入框上方显示可移除标签。标签与读取/提交错误显示在主页背景层之上。菜单内鼠标或触摸切换焦点不会提前关闭，Tab 移到外部或 Escape 仍可关闭；搜索框的 Enter 不会提交消息。选择能力后仍需填写具体需求并发送；没有可用模型时会显示原因和配置入口，不会静默禁用发送。

目标：新任务可把当前输入设为持久目标；已有会话使用独立编辑器，保存不会开始模型运行。已有目标必须勾选确认替换。工作流入口打开已有创建面板，不丢弃当前草稿。

创建器：插件清单是非执行 JSON，可使用 plugin_manifest_validate 校验；包含 entrypoint、动态代码等字段会被拒绝。可执行新功能仍需在源码中建立 bundled plugin、登记工具/模块/双语功能、运行结构检查并重新构建。技能使用项目 .xueness/skills/<name>/SKILL.md，skill_validate 与实际技能发现复用相同规则；验证不会执行技能内容。

Office：office_create 创建新文件；office_read 有界读取；office_replace 要求同一会话先完整读取相同路径，并传入返回的 expected_sha256。文件在读取后发生变化会拒绝覆盖。替换安装复用共享的原子替换：Windows 上短暂的共享冲突（WinError 5/32/33）最多重试约半秒，每次尝试前重新核对 expected_sha256；其它系统立即失败。截断或含图片的文本投影不给替换证明，应生成独立输出。替换会重新构建结构化文档，不能保留任意富版式、图表、嵌入对象或动画。XLSX 字符串以字面文本存储（包括 = 开头），不会执行公式。PPTX 使用简洁文字布局：每页标题不超过 60 字符，最多 20 个内容项，每项最多 400 字符、每页最多约 18 行。源码运行先执行 `python3 -m pip install -r desktop/requirements-office.txt`；桌面包已包含依赖。

搜图：使用设置中的真实图片服务与搜索密钥，不让文字模型编造图片链接。兼容 Brave Image Search，默认 service 模式使用官方图片端点；model 模式需单独填图片服务端点。返回图片/来源/缩略图地址及尺寸元数据；通过 HTTPS 与公网 DNS 检查不等于已获取或验证图片内容。最多检查 20 条/20 个主机，15 秒检查预算，不可重试的缺少密钥/不支持模式会明确报错。

上下文圆环：显示最近一次请求的输入上下文。服务报告的输入用量优先；本地估算与输入预算会明确标注，不能当作完整上下文窗口或实际 Token。切换模型后隐藏旧数据；缺失容量/报告显示未知，不显示虚构的 0%。它不累加整个会话的用量。

思考强度：输入框模型旁有独立按钮，标准和本地轻量模式均可使用。点击后打开渐变滑块；拖动只预览，松开后更新当前选择，方向键、Home/End 也可调整。取消拖动不修改选择，Escape 关闭并把焦点还给按钮；运行期间锁定。左端「默认」省略 `reasoning_effort`，复位按钮也恢复服务默认。选定档位通过准备请求及实际对话请求送达后端，可从模型菜单「设为默认」持久保存。

滑块仅显示模型配置声明或可信端点规则支持的档位，不把 Ultra 当成每个模型都有的能力。方舟 Coding Plan 的 `https://ark.cn-beijing.volces.com/api/coding/v3` 与 `deepseek-v4.1-flash` 精确组合可识别低/中等/高；明确声明的档位（包括空数组）仍优先。没有档位时按钮依然可见，并提供配置入口，不会虚构档位或请求参数。该交互属于 `sessions.runtime_model_switch`，端点识别和请求校验属于 providers 插件；插件关闭时沿用原有挂载及执行边界。

相关交互参考：[dsh-reasoning-slider](https://github.com/qjcnmd/dsh-reasoning-slider)、[DSH Claude Style Reasoning Slider](https://github.com/MEMZ-JZY/DSH-Claude-Style-Reasoning-Slider)。Xueness 使用自身的 React 组件，没有加载这些仓库的可执行代码。方舟档位范围依据[官方 Coding Plan 配置](https://docs.volcengine.com/docs/ark/coding-plan-personal-ai-codex?lang=zh)，Chat 请求字段依据[深度思考 API](https://docs.volcengine.com/docs/ark/deep-thinking?lang=zh)。本地模拟请求只能证明参数接线，不能证明服务商实际思考耗时或模型效果。

完全访问：每次从其它权限模式切入需确认，取消保留原模式。Web 后端拒绝未确认的新升级，已有完全访问会话可以继续。该模式免去常规文件、命令、浏览器、MCP 和联网工具的逐项审批。内置文件工具仍限制工作区路径，但本地命令以当前系统账户运行，可能操作工作区之外账户有权访问的内容；公网检查、系统权限与远程 SSH 具体操作批准继续生效。CLI 明确指定的权限模式仍遵守既有 CLI 语义。

每次新增产品能力都必须归属 bundled plugin，并在设置中的完整「已安装功能插件」目录中可见；扩展市场资源清单不能代替该目录。
