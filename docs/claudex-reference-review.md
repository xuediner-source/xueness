Claudex 是外观名称，替换旧「Codex 风格」的显示名称。它不改变模型、推理强度、权限、工具协议或插件开关。原 `colorPalette=claude` 在前端映射为 `claudex`；后端兼容旧值并接受新值，原 Xueness 外观仍可选择。

## 面向整个 Xueness 的功能

- **侧栏宽度调整**：两种外观都可拖动侧栏右边缘，分别记住本机宽度。双击边缘或按 Enter 恢复当前外观默认宽度；边缘获得焦点时可用左右方向键调整、Home/End 到达上下限。拖动期间按 Escape、取消指针或窗口失焦会撤销本次调整。窗口缩小时只限制显示宽度，保留原偏好；窄屏抽屉与折叠侧栏不显示拖动控件。禁用 sessions 后不读写宽度偏好或安装监听器。
- **会话正文搜索**：命令面板合并标题/工作区匹配和正文命中，显示内容摘要。后端分页搜索用户/助手正文及已压缩历史，不搜索系统提示、工具返回和独立思考字段。每页最多扫描 32 个会话，限制读取字节和工作时间；切换搜索词、关闭面板或禁用会话插件会中止后续前端请求。默认排除已归档会话，只显示允许工作区内的内容。过大或不可读文件明确提示跳过；达到 100 个命中或 5000 个扫描项时提示缩小关键词，不宣称已搜索全部历史。
- **结构化提问**：`ask_user` 保持必填 `question`，可附 1～3 个具备稳定 ID 的问题卡片、2～3 个选项和可选多选。每项始终允许自定义文字，选择不预填。后端严格校验选项、问题 ID、字符长度、工作区、会话租约和插件开关；问题 ID 绑定具体调用与选项内容。回答按内容摘要去重，保存后处于暂停状态，用户可仅保存或显式继续。答复不改动工具审批记录。旧自由文本实验开关继续保留；结构化提问由 sessions 和 planning 插件共同提供。
- **排队消息编辑**：待处理消息可折叠、编辑与取消。修改使用原文字校验，冲突时保留草稿；已领取或暂停中的当前轮次不可改。普通准备输入记录可编辑前缀，更新文字时保留附件、媒体 JSON 尾部和上下文快照。展开后的斜杠命令、无法确认前缀的旧准备输入要求取消并重新准备，避免展示新文字却执行旧提示词。
- **只读历史边界**：会话上下文读取增加打开后文件身份核验，拒绝路径检查之后被替换为另一文件的输入。

这些能力归属于 settings、sessions 和 planning 的已有插件目录及功能清单，在两种外观、浅色/深色和 Windows/macOS 中使用同一业务实现。验证结果和参考文件 SHA-256 位于本机 `E:\models\diagnostics\xueness-claudex-20261010`。屏幕尺寸模拟不代表原生 macOS 验收，后者由独立原生 CI 检查。
