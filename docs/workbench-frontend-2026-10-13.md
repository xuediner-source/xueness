# 工作台前端迁移：Windows preview 3

设置 → 外观现在提供两种独立布局：默认「ZCode 工作台」使用项目侧栏、顶部会话标签和输入框内的工作区选择；「Codex 工作台」使用图标导航栏、紧凑会话列表和居中首页，工作区选择位于输入框上方，会话从侧栏切换。浅色/深色独立选择。旧 `xueness` / `claudex`（含 `claude` 别名）配置继续有效，无需迁移用户数据。

preview 2 曾错误地让两项外观共用 Codex 侧栏与首页结构，preview 3 修复这个问题，并隔离各自的布局样式。切换仍使用同一份会话、草稿、模型和插件配置；回到 ZCode 时已打开的标签继续保留。

此前六阶段交付主要覆盖运行时、协议、插件和原生打包，不能代表 ZCode 工作台前端已完成迁移。本轮把布局和交互作为独立交付。

参考本地 ZCode `29628c9` 的 `app-shell/WorkspaceShellLayout.tsx`、`WorkspaceSidebar.tsx`、`v4/WorkbenchPane.tsx` 和 `ChatEmptyState.tsx`，用 Xueness 已有插件接口实现以下工作台结构。没有引入上游账户服务或将未接通的控件当成功能。

- 项目侧栏：展开与选择项目分开，显示目录、选中状态和新建任务入口；保留置顶、分组、归档与虚拟列表。
- 会话标签：切换沿用独立草稿和真实会话订阅；关闭标签不会删除、归档或停止会话。打开记录保存在当前 Web 入口的 localStorage，刷新可恢复。
- 项目首页与输入区：显示真实项目、最近会话、工作区选择和现有模型/权限/附件控制；新建任务继承当前工作区。
- 右侧工具区：文件、改动、Git、目录、子代理和会话信息在聊天旁打开。选择另一会话时文件/Git 数据随会话更新。
- 底部终端：使用现有 Windows ConPTY；隐藏面板保留终端，可以重连。结束进程仍使用「关闭终端」。
- 面板支持拖动、键盘调节和关闭；窄窗口改为上下排列。两种工作台共用真实工具与会话数据，各自保留独立布局。

功能归属是 `sessions.workbench_tabs`、`sessions.workbench_docks`，文件/Git/终端操作仍由原插件所有。禁用对应插件后隐藏控件并卸载内容，不启动其请求。插件管理入口始终保留。

验证使用隔离状态和真实生产构建，没有付费模型调用。`node webapp/verify-workbench-layout.mjs` 覆盖草稿切换、关闭标签、刷新恢复、工作区切换、真实终端重连、窄屏和插件禁用。前端全套、类型检查、构建/设计/包体门禁及插件结构检查按仓库要求执行；原生安装包通过 `desktop/scripts/check_app.py` 验证四种外观和渲染进程隔离。

本轮仍是单个活动会话视图。原版同时运行多个会话 pane 的分屏、拖拽组合与每个 pane 的独立订阅尚未迁移，不能把会话标签当成多 pane 已完成。macOS Intel 与 Apple Silicon 原生验收继续由所有者稍后执行。
