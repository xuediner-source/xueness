# 桌面浏览器资料

浏览器工具与资料管理归 `browser` 插件，资料导入还要求 `desktop` 插件生效。设置页的开关放在标题旁；启用后检测实际打包驱动和浏览器可执行文件，显示 Chrome、Edge 或 Chromium。检测不会打开页面，不表示已经验证网站访问或登录。

在桌面应用中打开「设置 → 浏览器 → 选择资料…」，选择本机 Chrome 资料并确认。先完全退出 Chrome，并结束运行中的任务。网页客户端不能读取本机 Chrome 资料；桌面集成或浏览器插件关闭后，不提供导入入口。资料列表只在点击选择后读取，页面不回显账户邮箱、完整磁盘路径或 Cookie 内容。

导入会把书签、历史、Cookie 和站点存储复制到状态目录下独立的 `browser-profile`，不会改动个人 Chrome 资料，也不复制已保存密码、扩展或全部浏览器偏好。导入需要确认替换 Xueness 已有资料。最多复制 256 MiB 和 10000 个文件/目录，超限、链接目录、正在使用或复制期变动均拒绝发布，并保留原有资料。新资料发布后，旧目录清理失败会明确提示，仍如实报告导入成功；「清除所有数据」会一并删除受管理的旧备份。

独立目录会跨启动保留；「清理缓存」保留站点资料，「清除所有数据」要求单独确认。旧版按进程编号创建的目录不属于本次导入目标，不会被自动删除。关闭浏览器插件会关闭其工作进程，重新开启仍使用独立目录。

Chrome 的加密和网站策略可能使复制后的登录状态无效，需要重新登录；不承诺迁移所有账号登录。独立目录符合 [Playwright 对持久浏览器上下文的说明](https://playwright.dev/docs/api/class-browsertype#browser-type-launch-persistent-context)及 [Chrome 对非默认调试资料目录的要求](https://developer.chrome.com/blog/remote-debugging-port)。浏览器动作仍须按既有 Gate 批准，启用插件或导入资料不会自动授予点击、填写和网络访问权限。

回归验证使用临时资料和假驱动，覆盖桌面识别、插件禁用、确认、任务占用、复制上限、原子替换、复制期变动及错误显示，不复制操作员的个人 Chrome 资料。
