## 后端约束

`GET /api/sessions/<id>/conversation` 从同一份 journal 生成 detail、timeline、completion 和消息修改版本，避免三个请求读到不同状态。队列仍是独立文件采样，不声明跨文件事务一致性。超过事件分页上限的保留历史完整返回，前端按回合虚拟显示。

`PATCH /api/sessions/<id>/message-actions` 归 sessions 插件，沿用 Host/Origin/CSRF、插件开关、会话锁及跨进程 lease。修改携带 SHA-256 journal 版本和真实 message index；运行中、过期版本、排队消息、未解决的早期工具批准或损坏元数据均拒绝。拒绝不改变磁盘 journal。反馈存在通用 `message_annotations` 元数据中，不修改模型消息协议；压缩时按保留消息对象重映射标注，丢弃已删除消息的反馈。

交付清单和工具成功证据保持各自意义。普通对话不展示空交付检查；从「更多操作 → 编辑交付清单」进入，有要求或失败时仍可见。结束、失败和未验证不会伪装成持续运行。未启动的旧任务使用紧凑恢复入口，不显示空红色错误栏。

历史轨道保持固定滚动总高，停靠点按真实下标定位，避免窗口替换过程中滚动范围短暂缩小。测量以实际 DOM 下标为准；键盘焦点在提交后校正，用户选择别的控件时不抢焦点，卸载时清理待执行的帧。

## 可重复验收和边界

`webapp/verify-zcode-conversation.mjs` 启动隔离 Python HTTP 后端，加载生产 `webapp/dist` 并检查截图、编辑、反馈、权限、历史和停止。模型为本地 fixture，不访问真实模型或用户状态；验证客户端与后端状态流，不代表真实模型速度、Token 用量或长任务成功率。退出时删除隔离状态。

配套回归为 `tests/test_message_actions.py`、前端完整测试、类型检查、生产构建、桌面测试和强制插件结构门禁。结果及安装数据保留凭据位于本机 `E:\models\diagnostics\xueness-zcode-comparison-20261008`。

本轮实际结果：854 项前端测试通过；83 项基础/会话/架构测试完成（1 项跳过），52 项 Web/消息操作回归此前通过；桌面测试 90 项通过、6 项因平台条件跳过。类型检查、生产构建、插件及资源包门禁通过。生产页面在两个独立启动中均通过 16 个视图和 11 项交互，无页面异常、无外部请求；351 回合实际只挂载 32 回合，连续四次首尾往返通过。最终安装器退出 0，293 个既有数据文件在安装前后 SHA-256 不变，1495 个后端文件符合 runtime manifest。没有提交、推送或发布。测试临时状态自动清理，安装校验后删除本轮 PyInstaller `.build` 的 1498 个生成文件（102,829,614 字节）；安装包及验收证据保留。

本轮采用同源会话布局和操作规范，不宣称整个应用、全部 ZCode 插件或所有屏幕已逐像素验收。ZCode 编辑消息的可选「同时回退工作区」未移植到此入口；Xueness Git 检查点与恢复仍是独立功能。本轮本地模型未在线，因此模型推理、联网任务成功率和多思考档位不能算已验证。

## Mac / Windows 源码统一（2026-10-09）

上述安装与未推送记录对应此前 Windows 本机验收。后续源码统一把同一套会话、标准/轻量输入工具栏、发送前权限确认、编辑反馈、分叉和一致快照用于 Windows、Intel Mac 与 Apple Silicon；没有独立的旧版 Mac 会话组件。Mac 保留原生窗口按钮、⌘ 快捷键、Dock 和真实系统权限入口，Windows 保留原生标题栏按钮、Ctrl 快捷键与托盘。

desktop 插件的自定义数据位置偏好现同时支持 Windows 与 macOS，格式与校验规则相同，环境变量仍优先；更新后无需依赖旧快捷方式才能找到既有数据。不改写或迁移用户数据。

生产浏览器验收新增 `XUENESS_CONVERSATION_PLATFORM=windows|macos`。每种平台响应分别通过 16 个深浅色、宽窄屏、标准/轻量及短/长会话视图和 11 项消息/权限交互，合计 32 个视图、22 项交互；另外 8 个平台/主题/宽度组合检查窗口避让、⌘/Ctrl 实际快捷键、设置与更新帮助。无页面异常或外部请求。前端 854 项、桌面 90 项通过（6 项平台条件跳过），类型检查、构建和插件门禁通过。

相关后端回归完成 434 项检查（26 项按测试条件跳过），覆盖插件边界、消息操作、模型流式兼容、轻量预算、交付状态和 Web 接口；没有运行后端全套或真实模型推理。

这些浏览器截图在 Windows 执行，明确记录 `simulatedOS` 与 `executionHost`，不算 Mac 原生安装验证。既有 `Desktop installers` 工作流分别在 Windows x64、Mac Intel x64 与 Mac arm64 原生 runner 中运行共享前端回归、桌面回归、冻结后端和真正的 Electron 打包应用检查。原生验证结果以对应 GitHub Actions 运行记录为准。源代码提交不替换既有 Release 安装包。
