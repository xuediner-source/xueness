# GitHub 源码与构建

公开主仓库保存 Xueness 应用源码、前端预构建资源、可选插件发布资源、安装器构建与使用说明。开发测试、测试 CI、验收、审查和压测材料在独立的私有验证库维护。

主仓库的 Desktop installers 工作流构建 Windows x64、macOS Intel 和 Apple Silicon 安装包，生成校验和并上传构建产物。测试由私有 QA 工作流手动针对指定源码提交运行；发布前应完成相关验证。

Stage desktop release 仍是手动入口，使用同一提交的安装包构建运行，校验更新元数据与资源摘要后创建/更新草稿。推送源码不会自动公开新 Release。

贡献与本机构建见 [贡献指南](../CONTRIBUTING.md)，测试使用私有验证库的说明。没有额外授权时，不改写仓库历史、不推送标签、不发布 Release、不上传凭据、账户数据、浏览器配置或模型权重。
