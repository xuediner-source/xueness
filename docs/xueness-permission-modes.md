# 会话权限设置

会话过程中可从标题栏的权限菜单切换设置。审批卡支持允许一次、项目内允许、完全访问、拒绝，以及补充处理方式；选择作用域按卡片提示生效。

| 设置 | 行为 |
|---|---|
| 计划 | 只读并先形成计划。 |
| 变更前确认 | 文件和命令变更按当前规则请求确认。 |
| 自动编辑 | 自动编辑文件；其它操作继续按规则确认。 |
| 守护执行 | 常规命令自动执行，已识别危险命令逐次确认。 |
| 完全访问 | 跳过应用内 disallow、deny、ask、alwaysAsk、远程逐项确认与工具工作区路径限制，不再逐条审批。 |

切回其它模式后恢复相应规则。完全访问的调用授权由宿主在内存中签发，模型、请求参数和状态文件不能自行伪造该能力。插件生命周期、HTTP 身份/Origin/CSRF、操作系统权限及工具输入、编码、版本和原子写入契约继续生效。

旧 CLI `--allow-write`、`--allow-edit`、`--allow-exec` 等参数继续用于显式授权当前运行；持久会话设置和 CLI 参数以当前入口帮助为准。功能由 permissions 基础设施以及 planning、sessions、files、remote 等所属插件共同落实，不应通过修改配置文本绕过批准入口。
