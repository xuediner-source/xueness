## Files changed

- `ts/plugins/deepseek_harness/src/bench/runner.ts` (new, production): minimal enabling runner. Because H06.01–H06.04 (runner/cases/profiler rounds) had no landed artifacts, H06.06 needed a callable runner to align the CLI with. `runBenchSuite(options)` executes pure scenario thunks, measures latency with an injectable `nowMs` clock, folds scenario-reported token/cache numbers into the `BenchRunSummary` shape from H06.05, and converts a throwing scenario into a failed case instead of aborting the suite. `defaultBenchCases()` provides three repeatable deterministic fixtures built on the real prefix stabilizer (`prefix-stable-append`, `prefix-churn`, `canonical-json-roundtrip`).
- `ts/plugins/deepseek_harness/src/index.ts` (edited): added the `deepseek_harness/bench` RPC method to `HARNESS_METHODS` and its dispatch branch — it runs the suite via `runBenchSuite`, optionally compares against a validated `baseline` row using `compareBenchRuns` (H06.05), and returns `{ ok, summary, compared, healthy, report }`. Added the `bench` action to `harnessCommand`. Added a `coerceBenchRun` validator for untrusted baseline payloads (rejects malformed shapes with `invalid_input`).
- `ts/plugins/deepseek_harness/test/bench-cli.test.ts` (new, tests): 11 unit tests.

## CLI exit-code alignment (H05.06 contract)

`xueness harness bench [baseline-json]` goes through the same `dispatch` as RPC, so CLI and RPC cannot drift, and its exit codes follow the structured H05.06 semantics:

- **0** — the bench ran and is healthy (all cases passed, or the baseline comparison found no regressions).
- **1** — the run completed but is unhealthy: failed cases, or the regression report against the supplied baseline is `healthy: false`.
- **2** — usage errors: unparseable baseline JSON, a baseline that fails `coerceBenchRun` validation, or unknown actions (unchanged from the existing `load|unload|list|verify` exits).

stdout is always a parseable JSON row including the `summary` and, when a baseline was given, the full regression `report` from H06.05.
