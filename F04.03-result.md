## Contract Invariants Satisfied (C-SES-03)

- **Hot memory vs durable history separated**: the hot turn-window only governs in-memory residency (turn window of 4, sealed-turn grace 120 s, 512-event cap, ModelRequest slimmed to routing metadata). It never truncates the JSONL ledger — every appended event remains a durable audit fact, and `readPage` always pages from the ledger.
- **Large-history pagination without repeated full reads**: pages read only the requested byte range via `readEventSlice`; appends update offsets incrementally and persist the index every 64 appends; rebuild checkpoints let a deep page (e.g. `after=1024`) reconstruct its snapshot without rescanning the prefix. Verified by `fullScans` staying at 1 (or 0 for cold loads) while paging 1200 events, including across fresh cold instances.
- **Cursors valid across recovery**: the ledger signature + epoch gate every index load; foreign epochs and ahead-of-head cursors raise `RuntimeEventConflict`; a corrupted index file is detected and repaired with exactly one rebuild; sequence numbers are re-validated on every slice read so gaps are surfaced as errors rather than silently skipped (the projection reducer additionally records `gaps` explicitly).
