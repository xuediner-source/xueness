## 实际交付

1. 订阅中心、返回模型监测和 WorkBuddy 号池为 GitHub 按需下载插件。新安装只有 32 个内置插件可用，三个可选插件未安装；核心保留全部 35 项元数据。正式安装包排除了三个插件的后端实现、网关/worker 资源及 6 个独立前端文件。
2. 市场只显示三个官方可选插件；技能、钩子、MCP 和协作代理不再作为重复安装条目。每个下载包通过固定 SHA-256 和逐文件摘要校验后发布，安装后默认停用。远程清单不能新增代码加载许可。
3. 在正式桌面端逐项点击“下载并安装”，三个插件均从本仓库真实下载成功，启用后对应面板可打开。后端回归验证热加载、旧清单不可激活、损坏包拒绝安装、卸载关闭服务并保留账号状态。
4. 技能页显示七项初始技能：`seagull-game-security`、`seagull-lab`、`seagull-license-security`、`seagull-memory`、`seagull-pentest`、`seagull-reverse`、`ask-user-question`。它们默认关闭，用户逐项启用；其他五项原有文档与可视化技能保留。
5. 逐项点击七个开关成功，重新加载后状态保留。关闭 `ask-user-question` 后，输入框技能目录不再列出它。后端测试同时验证标准与轻量模型目录、`Skill` / `skill_read` 与技能引用均拒绝关闭的技能；开关不修改内置文件。已存在的会话历史不被重写。
6. “从文件夹添加”保留新建入口，支持单技能与技能集合。实机导入含中文参考文档与 900,001 字节二进制附件的目录，复制内容逐字节一致；窄窗口下添加按钮在可视范围内。回归覆盖冲突整批拒绝、取消、未完成上传、错误格式与路径链接等边界。
7. `ask-user-question` 已适配 Xueness 标准模式 `AskUserQuestion`、轻量模式 `ask_user`，保留原始技能、示例、校验辅助文件与 MIT 声明。
8. GitHub 首页重建为品牌首屏、安装与运行入口、实机预览、插件/技能说明及验证文档；About 与主题标签同步更新。

## 部署与回退

本机更新保留原 Electron 宿主、卸载器、启动配置及用户数据，仅替换后端与界面资源。完整目录替换首次启动失败，已恢复原安装目录结构后完成更新并通过正式路径 UI 测试。之前的资源保存在本机验收目录的 `originals/backend-ts-before-final-update` 与 `originals/webapp-before-final-update`；完整候选安装目录也保留为回退证据。

## 验证边界

62 项跳过为现有 Python oracle 等外部条件，不计为通过。macOS Intel 没有上游 `dsh-ops@0.4.0` 原生 worker，因此该平台两个真实 worker 测试明确按平台条件跳过；Windows 的完整回归未跳过这两项。此报告的实机结论来自 Windows。

此前 WorkBuddy 长任务 Benchmark 已完成，包含未完成任务、65 分严格账本结果及 Windows 夹具换行问题；见 [原始压测报告](../20261026-workbuddy-benchmark)。本次插件和技能修订没有重新消耗真实模型配额，也未把 UI 成功或 HTTP 成功等同于复杂任务完成。
