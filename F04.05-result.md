## Model

- **CAS rollback** (`restoreFileChecked`): the before image is written only
  while the file on disk still matches the recorded *after* image
  (`exists` + sha-256 `hash`); any divergence raises `FileRewindError`
  before a byte is touched.
- **Per-file verification**: after each restore the file is re-imaged and
  must equal the recorded before image (`exists`, `hash`), otherwise the
  whole transaction aborts.
- **Traceable outcomes**: every applied rewind records
  `{messageId, operationIds, at, results}` in `session.file_rewind_history`
  (capped at 64, mirroring the compact timeline bound); each result row is
  `{path, action: restore|delete, restoredHash}` — `restoredHash` is null
  for files whose before image does not exist. The same array is returned
  as `results` from `applyFileRewind` and `file_rewind_last` keeps the
  latest pointer.
- **Compensation**: on any failure (divergence, verification, publication)
  already-touched files are restored to their pre-transaction images in
  reverse order, `file_history` is rolled back, and a previously absent
  `file_rewind_history` stays absent — a failed rewind leaves no trace
  entry.

## Contract invariants satisfied

- **C-SES-05** — before/after images are captured by the existing
  `filesHistoryExtension` (before execution, after commit); rewind is a
  CAS transaction: an externally modified file blocks the *entire* rollback
  (pre-check for every file, re-check at each write), failed transactions
  compensate already-restored files, and every successful undo leaves a
  traceable per-file result record.
- **C-SES-06** — recovery converges `started`/`retrying` compaction rows to
  `completed` only through a checkpoint with the *matching* `operationId`
  (a nearby unrelated summary never completes an operation), otherwise to
  `interrupted` with `reason: runtime_interrupted`; committed tool results,
  message history and archived originals are untouched by recovery; settled
  rows are never re-judged and an already-converged timeline publishes
  nothing.
