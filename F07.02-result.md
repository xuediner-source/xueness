# F07.02 Result — Hook Input & Output Protocol

- **Status**: Completed
- **Files changed this round**:
  - `ts/plugins/hooks/src/runner.ts`: `FireOptions.subjects` formalizes the matcher input per firing — `undefined` keeps the default (tool name + alias for tool events, none otherwise), an array matches those values (SessionStart matches its `source`), `null` skips the matcher entirely as upstream does for `UserPromptSubmit` and `Stop`. The stdin wire payload now always names its event: every hook receives `{ ...payload, hook_event_name: event }` whatever the caller passed in.

Timeout handling, per-hook containment and stdout parsing were already in place and are now pinned by contract tests.
  - `ts/plugins/hooks/test/hooks-protocol.test.ts` (new, 4 tests) checked against the ZCode v3.15.1 reference samples (`packages/core/tests/hooks-seven-events.test.ts`).
